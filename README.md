Un gestor de alumnos en CLI hecho con JAVA 24.0.1

Este gestor de alumnos tienes varias opciones : 

            0.- Salir
            1.- Alta alumno
            2.- Listar alumnos
            3.- Buscar alumnos por dni y mostrarlo
            4.- Modificar nota de Progrmacion
            5.- Modificar nota de BD
            6.- Mostrar estadisticas del curso
            7.- Eliminar alumno
            8.- Simulacion

Usado con constructores, encapsulaciones, metodos instancia, atributos privatos, getter/setter etc..
